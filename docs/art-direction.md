# Signal / Sanctuary art direction

An editorial developer journal inspired by the supplied portfolio reference and the bold science-fiction visual language of Bungie's Marathon. Uses original artwork rather than game assets, plus charcoal, acid lime, violet, large sans-serif headlines, fine rules, and geometric details. Misfit Sanctuary could not be visually inspected because its domain returned an SSL protocol error during this task; the connection is conceptual and through the existing brand link.

## Hero artwork

Generated with the built-in image-generation tool. Project asset: `public/images/journal-signal.webp`.

Prompt: Original cinematic sci-fi editorial collage, wide frame with dark negative space at left; faceless synthetic explorer at right in black ceramic helmet and technical clothing; acid-lime disk, brutalist monoliths, rocky terrain, translucent violet panel, restrained orange detail, tactile grain. High-fashion photography meets experimental science-fiction graphic design. No text, logos, weapons, or existing game character. Artwork only, not a website mockup.

The hero and preview card use this same artwork. Gentle drift and pointer movement respect reduced-motion preferences; the hero has a pause control. Dark is the new default, while the visitor's previously selected theme is retained.
